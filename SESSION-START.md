# Session-start: retired mandatory procedure

**There is no mandatory ASES session-start document.** The old `crosslink session last-handoff`, live VPS, startup daemon, CLI model recommender and automatic paid fallback procedures are **not current instructions**.

Begin from the **actual task** and retrieve only relevant current sources. Consult the [canonical Task-Scoped Information and Handoff Method](docs/methodology/ASES%20Task-Scoped%20Information%20and%20Handoff%20Method.md), the [current Skills index](skills/current/README.md), and the task's existing Git/Work Notes/Projektor records as appropriate. A bootstrap adapter is needed only if a particular harness demonstrably requires one. Execution/model permissions must be verified separately.

Original pre-deprecation text is preserved in [Git history at the source snapshot](https://github.com/rock-solid-sites/ASES/blob/2235d237044d6cb850f827d65baadd1fe3da5b34/SESSION-START.md), **for historical analysis only**. Existing references to this path must not treat it as current methodology.
