# ASES skills

**The only current ASES operational skill collection is [skills/current](current/README.md).** Select relevant skills by task; do not load the entire collection. The ChatGPT dispatcher uses the published read-only URLs in that index.

Stable methodology and project meaning belong in [current documentation](../docs/README.md); skills select and operationalize applicable sources. For public GitHub source exploration use the [current CodeGraph repository research skill](current/codegraph-actions-repository-research/SKILL.md). ATProto tooling is maintained separately in the [RSS Tools MCP registry](https://github.com/rock-solid-sites/rss-tools/blob/main/mcp/REGISTRY.md); the former ASES ATProto skill was a redirect, not an additional active procedure.

[Skill and Review Design History](../docs/historical/Skill%20and%20Review%20Design%20History.md) provides the earlier versions, rationale, discarded approaches, proposal/evaluation material and old packaging machinery. Archived copies are not executable skill entrypoints. The proposed ontology specialist is research; the current review modes and conceptual lens are described in the [AI Orchestration Guide](../docs/methodology/AI%20Orchestration%20Guide.md#review-modes-and-provenance). No separate role, package or service is required merely to perform conceptual review.
