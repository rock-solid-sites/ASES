# Unix descriptor transfer: preregistered mechanism experiment

Hypothesis: a request's current bearer value and connection-time `SO_PEERCRED` cannot distinguish the original connector from another process that later receives its connected descriptor via `SCM_RIGHTS`. A receiver with `SO_PASSCRED` enabled before connection should receive per-message `SCM_CREDENTIALS` distinguishing the original replacement sender from the recipient of the same descriptor. Predictions: (1) replacement sender's current request is received with its PID; (2) after transfer, old sender sends the identical current value over the same connection and `SO_PEERCRED` remains the replacement PID, while per-message PID is old; (3) a current-token-plus-connection-PID rule would admit both, and a current-token-plus-per-message-PID rule would admit replacement and refuse old. Observations and rule evaluation are kept separate.

Premises: local Linux Unix `SOCK_SEQPACKET`, the kernel's delivered ancillary credentials and `SO_PEERCRED` are trusted, same UID/GID but distinct live PIDs in one PID namespace; the child relation is verified while both are alive. The replacement's PID is pre-authorized by the supervising fixture, no process intentionally forges ancillary credentials, and no privileged adversary changes credentials or PID namespace. The fixed request value is a test stand-in for current bearer evidence, not a credential implementation. The server reads one message per record; timing and provenance of each receive are recorded. No production process, ingress, policy, storage, network, or capability isolation is changed. This tests a local mechanism; it is not F1 or F3 acceptance, a complete authentication design, or proof against privileged impersonation, process/PID reuse, namespace crossings, or compromised replacement.

This fixture does not claim to run that prototype. Closure's realization boundary already documents these OS semantics; this is a local discriminating observation, not a new upstream discovery. The 2026-11-02 proposals remain provisional.
