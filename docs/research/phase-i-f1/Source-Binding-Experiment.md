Hypothesis: with valid path grants and the same current generation available to two participants, the inherited guard alone admits the old participant; adding a trusted per-use source association allows the replacement and rejects the old participant. A stale generation must remain denied even for the replacement. A separately evaluated source invariant must detect the weakened association. This is a finite model discriminator, not host evidence or a claim that physical source binding exists.

Bound: exactly one old and one replacement participant, one current and one stale generation, one C/SINK write request for each of three cases, each attempted at most once. Trusted inputs: authoritative per-use source label and mapping of replacement to current ingress, pre-established grant state, serialized abstract admission. Weakened association: 8 states, 12 attempted edges, 8 accepted, 4 denied, 4 violating edges. Neither search hit its 100-state cap. The counts are graph edges, not distinct real-world requests; all four violation edges represent the same old-source case at different sets of previously attempted cases. Attempts consumed by denial update *fixture bookkeeping*, not F1 protected state. The experiment invokes F1's `resolve` on both initial grant events and for every admitted use; inherited use effects only append an observation, and no subsequent guard depends on that log. It therefore retains a fixed F1 grant state and tracks acceptance separately.

The current replacement succeeds. The old participant holding the *same current generation* is refused by the added trusted association but accepted by the inherited guard when the association is disabled, and a separate observer detects the unauthorized physical-source effect. Replacement with stale generation is refused in both variants. This separates source-binding from generation freshness and demonstrates that the mutant has a reachable, otherwise-authorized request. These are bounded evidence-based observations, not proof of an implementation or of real physical source labels. The source value is a trusted fixture input, not a caller-provided string, and no real source authentication or non-transfer property was tested. Current grants, serialized admission, independent source observation and the authorized mapping are assumptions.
