# Independent C11 observation fields — preregistration

`Consumer-Observation-Continuity.md` compared two worlds in which all four required observation values changed together and removed all four together. That does not isolate whether each observation is independently unrecoverable from the others: the tiny two-world corpus makes them perfectly correlated. This follow-up removes that avoidable limitation without asserting a canonical schema.

Hypothesis: take the complete 16-world product of two opaque values for each of the same four declared consumer observations (identity/genesis, created-by, project, accepted consumer evidence), with accepted x and inherited F1 state fixed. For each world run the same eight F1 events from the prior experiment. Full retention returns the exact tuple. For each of four independently weakened variants erase only that one observation on stop while retaining the other three; each mutation produces eight pairs of distinct worlds that are observationally identical after recovery although their erased observations differ, and its independent oracle detects exactly one missing field per world. This is an information distinction in a fully crossed finite fixture: no omitted field can be reconstructed from the retained fields within these worlds. It does not establish independence or impossibility for every actual consumer or representation. Full-retention results and unaffected fields supply positive controls.

Exactly 16 worlds times five variants, eight inherited F1 committed events each, no transition-graph exploration; enumerate all worlds and mutation choices and explicitly count pairs, per-field mismatches and invariant failures. F1 `C` is a symbolic slot with separate world interpretations, and observation/evidence acceptance and retention are stipulated wrapper facts, not modeled holder behavior. Hash and report raw result, all counts and truncation, syntax and 30-second bound. Existing `consumer_observation_continuity.py` defines fields/events and supplies the query; its other two fixed-world assertions are not used as a test oracle. No physical recovery, consumer implementation, source verification or canonical ontology adoption; C11/F1/F5 remain incomplete.
