# Paired-state examples correspond to the frozen combinational RTL

Preregistered at `a58447c65`. The unchanged `kernel0_step` matches the frozen Python oracle for all six settled input vectors: two parent-relationship vectors in independent profile, the same two in coupled profile, and two coupled data-state vectors. The paired parent inputs share rights yet yield distinct child-right successors; the coupled data inputs share rights and parent but yield commit versus deny. This corroborates these specific oracle counterexamples in the concrete combinational RTL, which itself receives the whole state. It does not show an RTL defect or imply that RTL implements a reduced observation mask.

The deliberately corrupted expected successor was rejected at case 0 in each profile with actual and expected outputs in the raw log; both positive runs exit 0, both negative runs exit 1. The harness checks catalog membership, invariants and equalities defining the pairs. Parent states are constructed via successful grant/delegate requests; the data variant is legal but not established reachable by this test.
