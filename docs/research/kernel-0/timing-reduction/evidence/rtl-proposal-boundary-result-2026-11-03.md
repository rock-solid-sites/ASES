Preregistered at `f3ee1fbce`. All four fixed cases match the oracle for the complete input word at the clock edge. When H is settled before the edge and B appears afterward, the machine commits H; when A is present at the edge and H/B appear afterward, it commits A and the later changes leave stored state unchanged before the next edge. The intentionally wrong expectation that H should yield A's successor fails at case 2.

This exposes the boundary of this digital machine: it resolves the complete word supplied at the sampling edge, so a producer-side notion of an intact intended request cannot be inferred from the sampled word alone.
