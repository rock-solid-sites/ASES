# Encoding representation/resource audit

## First verdict

**Conditional pass for the stated representation claim.** The reviewed 18-bit register plus decoded 22-bit observation refines the reused independent-profile `kernel0_step` transition over every 18-bit compact input with a valid code, and the codec is a round trip for every 22-bit word satisfying the three-right exclusivity shape. This supports the claimed equivalence under the declared at-most-one-active-rights condition for a0/a1/a2. It does not establish the reused transition's original semantics, minimal state or gate count, physical timing, or equivalence to another profile.

The result depends on trusted synchronous reset and whole-proposal sampling. `kernel0_compact_machine` clears the compact register and completion outputs on a rising reset edge; otherwise it updates state only on `valid`, and derives `resolved`/`committed` on that same edge. The raw-source SAT contract is combinational and the 21-cycle sequence is finite. Neither establishes clock/reset integrity, arbitrary input setup/hold behavior, nor an unbounded physical implementation.

## Independent inspection

The compact state keeps bits `[21:20]`, `[19:17]`, and `[7:0]` directly, and packs the mutually exclusive three 3-bit rights fields into codes 0–21. The decoder is a left inverse for those codes. Codes 22–31 are rejected by `valid_code`; the machine's observer maps them to `22'h000002`, while the step holds an invalid compact register and declines commit. Such codes are outside reset-reachable operation; the proof does not show behavior from arbitrary uninitialized compact hardware state.

`codec_contract` checks the encode/decode identity for all raw wide words satisfying only the right-field exclusivity shape. `step_contract` checks the reused original transition and compact transition for all proposal bit patterns and all valid compact codes, including semantically invalid decoded wide states. It compares both successor and commit. Thus it avoids relying on catalog-only proposals for this one-step result. This is a representation refinement against the frozen RTL, not a proof that the RTL implements the finite-model semantics.

The logged codec and step SAT jobs both exited 0 with `SAT proof finished - no model found: SUCCESS!`. The code mutation (`code-5'd7` to `code-5'd6`) was detected by the codec contract: Yosys exited 1 with `Called with -verify and proof did fail!`. The compiled literal sequence exited 0 and reported `PASS sequential cycles=21`; its encoding mutation exited 1 at sequence 8 with a state mismatch. These are executed producer artifacts inspected here; this audit did not rerun SAT or simulation.
