# Final Report Template

Based on ASES methodology (findings → syntheses → retrospective knowledge base)

---

# Project Completion Report: [Project Name]

## 1. Executive Summary
- Project scope & objectives
- Key outcomes (what was delivered)
- Methodological approach used

## 2. Findings Summary
- Key findings (reference to `findings/` entries)
- Evidence supporting each finding
- Confidence levels per finding

## 3. Synthesis
- Cross-cutting themes across findings
- Relationship to prior assumptions (reference Assumption Register)
- Contradictions with prior expectations

## 4. Retrospective Knowledge Base Updates
- New rules added to Master Retrospective Log
- Failed approaches documented
- Revised assumptions (reference Assumption Register updates)

## 5. Model Evaluation Summary
- Models used (names, versions, providers)
- Task categories evaluated
- Key strengths/weaknesses per model (reference AI Capability Registry)
- Notable failure modes observed
- Confidence levels in assessments

## 6. Adversarial Review Outcomes
- Summary of adversarial reviews conducted
- Critical/high/medium findings
- Remediation status
- Any adversarial consensus vs project authority decisions

## 7. Lessons Learned / Recommendations
- What worked well
- What failed
- Process improvements for next project
- Capability registry updates needed

## 8. Evidence Registry
- Links to supporting evidence (findings, syntheses, reviews)
- Confidence levels per claim
- Traceability to source artifacts
