# Session-end: retired mandatory procedure

**There is no required universal ASES session-end file or Crosslink handoff.** Persist the task's observed result, evidence, source revision, WHAT-NOT-TESTED, blockers and next transition in the existing authoritative work record (Git for source/evidence, Work Notes for agent position, Projektor for human decisions), following the [canonical task-scoped handoff method](methodology/ASES%20Task-Scoped%20Information%20and%20Handoff%20Method.md). Do not claim task completion without verified durable evidence.

Old `crosslink session end --notes`, `crosslink kickoff cleanup` and orchestration-guard procedures are not current. Previous content is preserved [in repository history](https://github.com/rock-solid-sites/ASES/blob/2235d237044d6cb850f827d65baadd1fe3da5b34/docs/SESSION-END.md) as historical evidence, not instructions for the present launcher.
